# Mascot art brief

The mascot is a sprite: one image per expression (or a few frames for the
animated ones), listed in `public/mascot/mascot.json`. Swapping the art means
replacing the files and editing that JSON — no code changes.

The art (Candy, a little candle) is generated by
`npm run mascot` (`scripts/gen-placeholder-mascot.mjs`).

## What to deliver

| State       | When it shows                                              | Frames                      |
|-------------|------------------------------------------------------------|-----------------------------|
| `idle`      | Default, watching the market                               | 1 + eyes (+ blink)           |
| `happy`     | Watchlist green on average (1h); also when clicked         | 1                           |
| `celebrate` | A token +15% in 5 min, or an "up" alert fires              | 2–4 (loops)                 |
| `worried`   | Watchlist red on average (1h)                              | 1 + eyes (+ blink)           |
| `shocked`   | A token −15% in 5 min, a "down" alert, a liquidity warning | 1                           |
| `sleepy`    | Late at night, or the app paused                           | 1 (the app adds floating z's)|
| `alert`     | A liquidity or max-trades alert pops up                    | 1 (the app adds a "!")       |
| `tired`     | Break reminder, post-loss cooldown                         | 1                           |
| `stop`      | Today's loss limit reached                                 | 1 + eyes (+ blink)           |
| `confused`  | No data (offline), or clicked too many times               | 1 (the app adds a "?")       |
| `love`      | Mouse rests on the mascot                                  | 1 (the app adds hearts)      |
| `wave`      | Launch greeting                                            | 2 (loops)                   |
| `proud`     | A win logged, a break taken                                | 1 (the app adds sparkles)    |
| `sad`       | A loss logged                                              | 1 + eyes (+ blink)           |
| `bored`     | Market quiet during the day                                | 1 (the app adds "…")         |
| `focused`   | A watchlist token's 5-minute volume spikes                 | 1 + eyes                     |
| `nervous`   | Fear & Greed at extreme fear                               | 1 + eyes (the app trembles)  |
| `curious`   | A token added to the watchlist                             | 1 + eyes (+ blink)           |
| `angry`     | A trade logged past the day's max; poked 8 times           | 1 + eyes (the app trembles)  |
| `excited`   | Fear & Greed at extreme greed                              | 1 + eyes (the app adds sparkles) |
| `relieved`  | A cooldown ends                                            | 1                           |
| `dizzy`     | A token swings hard both ways; poked 5 times               | 1 (the app wobbles)          |
| `cool`      | The day's recap card shared                                | 1 + eyes                     |
| `sick`      | Watchlist down 15% or more on average (1h)                 | 1                           |

Only `idle` is required: a missing state falls back to a close relative
(`celebrate` → `happy` → `idle`, `shocked` → `worried` → `idle`, …), so the art
can arrive in batches.

## Format

- **PNG with transparency** (or SVG), square, **512 × 512** px. It is shown from
  28 px (the compact ticker) up to about 100 px, so it has to read at 28 px:
  bold shapes, clear eyes, no thin lines.
- The character should sit centred with a little room at the top for the
  effects (z's, "!", hearts) and fill most of the canvas width.
- Keep the **same body colour in every expression**, except the loss moods:
  the trader's colour choice tints it (a CSS filter), so a mood drawn in
  another colour would come out wrong. Candy is a candle: worried, shocked,
  sad and stop are drawn red and marked `"tint": false` in `mascot.json`,
  so they stay red under any colour. Otherwise moods show in the face, brows,
  sweat and effects.
- The island background is **black**: no dark outlines that vanish on it, or
  add a light rim.
- Keep every frame of an animation in the same position, so frames swap
  without jumping.

## mascot.json

```json
{
  "name": "Your mascot",
  "states": {
    "idle":      { "frames": ["idle.png"], "eyes": "eyes/open.png", "eyesBlink": "eyes/blink.png", "motion": "breathe" },
    "celebrate": { "frames": ["celebrate-1.png", "celebrate-2.png"], "fps": 4, "motion": "bounce", "fx": "sparkles" }
  }
}
```

- `frames` — images in `public/mascot/`, played in order at `fps`.
- `eyes` — optional: the eyes (or just the pupils) on their own transparent
  image, same canvas. They follow the mouse a few pixels, so the frames leave
  them out (keep what must not move, like the whites of wide eyes, in the
  frame). Closed or half-shut eyes can stay in the frame with no `eyes`.
- `eyesBlink` — optional eyes image shown for 140 ms every few seconds.
- `blink` — for art with no eyes layer: a whole frame shown for 140 ms every
  few seconds instead.
- `still/idle`, `still/happy`, `still/alert` (whole faces, eyes included) are
  used where a single image shows: the browser tab icon, notifications and
  the tour's title cards.
- `motion` — body movement added by the app: `breathe`, `bounce`, `jump`,
  `shake`, `sway`, `droop` or `none`.
- `fx` — optional effect drawn above the head: `zzz`, `bang`, `question`,
  `hearts`, `sparkles`.

## Accessories

Hats go under `outfits` and face accessories (glasses, a mustache…) under
`faces` in `mascot.json`, by id (the ids the settings list). Each is an image
on the same canvas as the frames, drawn over every frame; the face sits under
the hat, so the two can be worn together. Colours are CSS filters over the
frames only (`src/mascot/skins.ts`), so accessories keep their own colours.

```json
"outfits": { "cap": "outfits/cap.svg" },
"faces": { "shades": "faces/shades.svg" }
```

## Costumes

A costume redraws the whole mascot: under `costumes` in `mascot.json`, by id
(the ids in `COSTUME_IDS`, `src/core/state.ts`), a name and its own
`states`, written like the main ones. Give every state frames (a test checks);
motion and effects can follow Candy's. Hats and faces still go on top, so keep
the eyes and the top of the head where Candy has them; the colour pick does
not apply, a costume keeps its own colours, and every costume has arms and
legs. Gengar, Spiderman, Shadow and V are drawn by
`scripts/gen-placeholder-mascot.mjs` into `costumes/<id>/`.

```json
"costumes": { "gengar": { "name": "Gengar", "states": { "idle": { "frames": ["costumes/gengar/idle.svg"] } } } }
```

Check every expression at once in **Settings → Mascot**, and in the demo
(`npm run dev`, then open `/demo.html`).

## App icon

`npm run icons` draws the icon into `src-tauri/icons/`. To change it, replace `32x32.png`, `128x128.png`, `128x128@2x.png` (256 px),
`icon.png` (512 px) and `icon.ico` (16–256 px), or run
`npx tauri icon path/to/icon-1024.png`.
